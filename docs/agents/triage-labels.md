# Statuts de triage

| Rôle canonique | Valeur de Status | Signification |
| --- | --- | --- |
| needs-triage | needs-triage | Ticket à évaluer |
| needs-info | needs-info | Informations attendues |
| ready-for-agent | ready-for-agent | Prêt pour réalisation par un agent |
| ready-for-human | ready-for-human | Réalisation humaine nécessaire |
| wontfix | wontfix | Ticket qui ne sera pas traité |

Quand une compétence mentionne un rôle de triage, utiliser la valeur
correspondante dans la ligne `Status:` du ticket Markdown.
