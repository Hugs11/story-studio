Le **Menu racine** est le point de départ de la structure d’un pack dans Story Studio.

Il remplit deux rôles :

- il définit la **présentation du pack** dans le menu principal de la Lunii, avec son **Image Lunii** et son **Titre audio** ;
- il contient les premiers **Dossiers**, **Histoires** ou packs auxquels l’enfant accède après avoir ouvert le pack.

Le parcours ressemble donc généralement à ceci :

```text
Menu principal de la Lunii

Menu racine
        ↓ OK

Entrée dans le pack
        ↓
Premier élément sous le Menu racine
        ↔ molette ↔
Autres éléments du même niveau
```

L’ordre des éléments placés sous le Menu racine détermine leur ordre de parcours avec la molette.

## Ce que le Menu racine peut contenir

Dans un pack créé avec l’**Éditeur libre**, le Menu racine peut contenir directement :

- des [Histoires](/story-studio/docs/histoire/) ;
- des [Dossiers](/story-studio/docs/dossier/) ;
- des archives **ZIP** ou **7z**, pour proposer des packs complets comme choix ;
- ou une combinaison de ces éléments.

Une archive peut être utilisée directement ou
[extraite en éléments modifiables](/story-studio/docs/modifier-un-pack-existant/#extraire-un-pack-déjà-présent-dans-larbre)
si sa structure est prise en charge.

## Menu racine et Dossier

Le **Menu racine** et un **Dossier** peuvent tous les deux contenir plusieurs éléments, mais ils
n’ont pas le même rôle.

Le Menu racine est unique : il représente le pack et son premier niveau de navigation.

Un Dossier est au contraire un élément du parcours. Il permet de regrouper des Histoires, de créer
un niveau de choix, de poser une question ou d’ajouter une transition.

### Histoires directement sous le Menu racine

Avec :

```text
Menu racine
├── Histoire « Le Renard »
├── Histoire « Le Hibou »
└── Histoire « Le Lion »
```

l’enfant voit d’abord l’Image Lunii du pack et entend son Titre audio dans le menu principal de la
Lunii.

Après avoir appuyé sur **OK**, il peut immédiatement choisir entre les trois Histoires avec la
molette.

```text
Menu racine
        ↓ OK
Histoire « Le Renard »
        ↔ molette ↔
Histoire « Le Hibou »
        ↔ molette ↔
Histoire « Le Lion »
```

Aucun Dossier intermédiaire n’est nécessaire.

### Un seul Dossier sous le Menu racine

Avec :

```text
Menu racine
└── Dossier « Animaux »
    ├── Histoire « Le Renard »
    └── Histoire « Le Hibou »
```

le Dossier **Animaux** constitue le premier niveau du parcours.

Comme il est l’unique élément du Menu racine, Story Studio l’atteint automatiquement après
l’ouverture du pack. Son **Audio de sélection** peut alors présenter ce choix ou poser une question,
par exemple :

> « Quel animal veux-tu écouter ? »

L’enfant peut ensuite parcourir les Histoires du Dossier avec la molette.

```text
Menu racine
        ↓ OK
Dossier « Animaux »
« Quel animal veux-tu écouter ? »
        ↓
Histoire « Le Renard »
        ↔ molette ↔
Histoire « Le Hibou »
```

Si ce Dossier ne contient lui-même qu’un seul élément, Story Studio simplifie davantage le parcours
afin d’éviter une validation intermédiaire inutile. La **Lecture automatique** est alors imposée et
la **Molette de sélection** désactivée.

[Découvrir les différents usages et réglages d’un Dossier](/story-studio/docs/dossier/)

### Plusieurs éléments sous le Menu racine

Un Dossier peut également être proposé parmi d’autres choix :

```text
Menu racine
├── Dossier « Animaux »
├── Dossier « Espace »
└── Histoire « Le Voyage du nuage »
```

Après avoir ouvert le pack, l’enfant choisit alors entre ces éléments avec la molette.

S’il sélectionne **Animaux** et appuie sur **OK**, il entre dans ce Dossier et découvre les Histoires
qu’il contient.

Chaque Dossier ajoute donc un niveau au parcours lorsqu’il sert réellement de choix ou de transition.

## Dans l’Éditeur simplifié

L’**Éditeur simplifié** est destiné aux packs contenant une seule Histoire. Story Studio masque donc
la structure habituelle du Menu racine et affiche directement **Mon histoire**.

Son image et son **Titre audio** présentent le pack dans le menu principal de la Lunii. Après
validation avec **OK**, le **Récit complet** est joué directement.

```text
Image + Titre audio du pack
        ↓ OK
Récit complet
```

Il n’y a donc pas de second écran de sélection entre la présentation du pack et son récit.

Si tu veux créer plusieurs choix, utiliser des Dossiers ou personnaliser la navigation, passe à
l’[Éditeur libre](/story-studio/docs/editeur-libre/).

## Image Lunii et vignette catalogue

Plusieurs éléments servent à présenter le pack, mais ils n’ont pas la même destination :

| Élément | Rôle |
|---|---|
| **Image Lunii** | image affichée dans le menu principal de la Lunii lorsque le pack est sélectionné |
| **Titre audio** | son joué au même moment pour annoncer le pack |
| **Vignette catalogue** | image utilisée par les bibliothèques compatibles, comme STUdio ou LuniiQt |

L’**Image Lunii** est adaptée au format **320 × 240 px** lors de l’export.

Le réglage **Utiliser la même image pour la Lunii et la vignette catalogue** permet d’utiliser un
seul visuel pour les deux. Sans ce réglage, les deux images doivent être choisies indépendamment.

[Voir comment la molette, OK et Accueil parcourent le pack](/story-studio/docs/navigation/)
