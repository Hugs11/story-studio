Le **Menu racine** est le point de départ obligatoire de chaque pack. Il présente le pack dans le
menu principal de la Lunii et contient les premiers éléments de son parcours.

Avant d’entrer dans le pack, l’enfant voit son **Image Lunii** et entend son **Titre audio**.
Lorsqu’il valide avec **OK**, il entre dans la navigation interne et découvre les éléments placés
directement sous le Menu racine.

```text
Sélection du pack
        ↓
Image Lunii affichée + Titre audio joué
        ↓ OK
Premier choix du pack
        ↔ molette ↔
Autres choix du même niveau
```

L’ordre de ces éléments dans l’arbre détermine leur ordre de parcours avec la molette.

Si un Dossier est l’unique élément du Menu racine, Story Studio entre automatiquement dans son
contenu afin d’éviter une validation intermédiaire inutile. Son Audio de sélection peut néanmoins
servir d’introduction avant le premier choix.

:::note[Sélection du pack ou premier choix]
La **sélection du pack** correspond à sa couverture dans le menu principal de la Lunii.

Le **premier choix du pack** se trouve après avoir validé cette couverture avec **OK** : l’enfant
est alors entré dans la navigation interne du pack.
:::

## Ce que le Menu racine peut contenir

Dans un pack créé avec l’**Éditeur libre**, le Menu racine peut contenir directement :

- des [Histoires](/story-studio/docs/histoire/) ;
- des [Dossiers](/story-studio/docs/dossier/) ;
- des **ZIP**, pour proposer des packs complets comme choix ;
- ou une combinaison de ces éléments.

Un ZIP peut être utilisé directement ou
[extrait en éléments modifiables](/story-studio/docs/importer-et-extraire-un-pack/)
si sa structure est prise en charge.

## Menu racine et Dossier

Le **Menu racine** et un **Dossier** peuvent tous les deux contenir plusieurs éléments, mais ils
n’ont pas le même rôle.

Le Menu racine est unique : il représente le pack et contient le premier niveau de son parcours.
Un Dossier est un élément de ce parcours et peut ajouter une étape supplémentaire.

### Sans Dossier

```text
Menu racine
├── Histoire « Le Renard »
└── Histoire « Le Hibou »
```

L’enfant entre dans le pack et peut immédiatement choisir entre les deux Histoires avec la molette.

### Avec un Dossier

```text
Menu racine
└── Dossier « Animaux »
    ├── Histoire « Le Renard »
    └── Histoire « Le Hibou »
```

L’enfant entre d’abord dans le Dossier **Animaux**, puis choisit entre les deux Histoires.

Le Dossier ajoute donc une étape dans le parcours. Il est utile lorsqu’il sert à regrouper des
Histoires, poser une question, introduire une partie du pack ou créer une transition.

[Découvrir les différents usages d’un Dossier](/story-studio/docs/dossier/)

## Dans l’Éditeur simplifié

L’**Éditeur simplifié** est destiné aux packs contenant une seule histoire. Story Studio masque donc
la structure habituelle du Menu racine et affiche directement **Mon histoire**.

Son image et son **Titre audio** présentent l’histoire dans le menu principal de la Lunii. Après
validation avec **OK**, le **Récit complet** est joué.

Si tu veux créer plusieurs choix, utiliser des Dossiers ou personnaliser la navigation, passe à
l’[Éditeur libre](/story-studio/docs/editeur-libre/).

## Image Lunii, vignette et métadonnées

Plusieurs éléments servent à présenter le pack, mais ils n’ont pas la même destination :

| Élément | Rôle |
|---|---|
| **Image Lunii** | image affichée sur la boîte pour présenter le pack |
| **Titre audio** | son entendu lorsque le pack est sélectionné dans le menu principal |
| **Vignette catalogue** | image utilisée par les bibliothèques compatibles, comme STUdio ou LuniiQt |
| **Métadonnées du pack** | titre, auteur, version, âge et autres informations décrivant le pack exporté |

L’**Image Lunii** est adaptée au format **320 × 240 px** lors de l’export.

Le réglage **Utiliser la même image pour la Lunii et la vignette catalogue** permet d’utiliser un
seul visuel pour les deux. Sans ce réglage, les deux images peuvent être choisies indépendamment.
