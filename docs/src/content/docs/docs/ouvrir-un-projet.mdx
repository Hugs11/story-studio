---
title: Ouvrir un projet
description: Reprendre un fichier .mbah, un projet récent ou une session récupérable.
---

L’entrée **Ouvrir un projet** charge un fichier `.mbah` déjà enregistré. Les projets utilisés
récemment apparaissent également sur l’accueil pour une reprise plus rapide.

## Choisir le projet

Sélectionne le fichier `.mbah`. Story Studio charge sa structure, ses réglages, son catalogue Médias
et les chemins vers les fichiers associés.

Un ZIP généré n’est pas le projet source : utilise **Modifier un pack existant** si tu ne disposes
que de l’archive finale.

## Retrouver les médias

Si un fichier a été déplacé, renommé ou se trouve sur un disque non monté, la fenêtre **Médias
introuvables** propose de rechercher et relier les références. Vérifie les correspondances avant de
les appliquer et d’enregistrer.

Un projet peut référencer des fichiers externes ou des copies placées dans son workspace. Le fichier
`.mbah` seul ne suffit donc pas toujours pour transférer tout le projet vers une autre machine.

## Projet récent ou récupérable

Les projets récents affichés sur l’accueil pointent vers leur dernier emplacement connu. Une carte
**Projet récupérable** correspond au contraire à une session non enregistrée retrouvée après une
interruption.

Ouvre cette reprise, vérifie son contenu puis utilise **Enregistrer comme projet**. Ignorer la carte
supprime la reprise temporaire concernée.

:::tip[Astuce]
Avant de déplacer un projet vers une autre machine, utilise **Préférences → Gestion des projets et
médias → Consolider le projet**. Le `.mbah` et tous ses médias référencés seront copiés ensemble sans
supprimer les originaux.
:::
