---
title: Workspace et fichiers de projet
description: Comprendre le fichier .mbah, les médias gérés et les dossiers utilisés par Story Studio.
---

Le fichier **`.mbah`** contient la structure et les réglages du projet. Les images, audios, archives
et exports restent des fichiers séparés. Le **workspace** est l’emplacement de référence dans lequel
Story Studio peut organiser ces fichiers.

## Choisir l’emplacement de travail

Dans **Préférences → Gestion des projets et médias**, tu peux choisir le workspace et décider si les
nouveaux projets doivent l’utiliser immédiatement.

Par défaut, un nouveau travail commence dans une
[session temporaire](/story-studio/docs/sessions-temporaires-et-recuperation/) afin de ne pas imposer
un emplacement avant le premier enregistrement.

L’option **Copier les fichiers importés dans l’emplacement de travail** crée une copie gérée des ZIP,
7z, images et audios choisis. Lorsqu’elle est désactivée, le projet peut continuer à référencer le
fichier à son emplacement d’origine.

## Dossiers gérés

| Dossier | Contenu |
|---|---|
| `fichiers-importes/` | copies de médias importés et assemblages audio |
| `enregistrements/` | sons enregistrés avec le microphone |
| `voix-generees/` | voix produites par Piper ou XTTS |
| `images-generees/` | images générées ou dérivées par l’éditeur d’images |
| `zips-extraits/` | fichiers récupérés lors de l’extraction de packs |
| `sauvegardes/` | emplacement proposé pour les projets et sauvegardes automatiques |
| `versions-securite/` | versions de sécurité créées lors des enregistrements |
| `exports/` | destination proposée pour les packs générés |

Les fichiers gérés peuvent recevoir un préfixe dérivé du nom du projet afin que plusieurs projets
partagent le même workspace sans collision.

## Fichiers externes et fichiers gérés

Un fichier externe reste sous ta responsabilité : s’il est déplacé, renommé ou si son disque n’est
plus monté, Story Studio demandera de le relier. Copier les imports dans le workspace réduit ce
risque, au prix d’une copie supplémentaire.

Le Gestionnaire de médias ne propose une suppression physique que pour certains fichiers inutilisés
placés dans les dossiers gérés. Une source externe est retirée du catalogue ou du projet, mais n’est
pas effacée du disque.

## Consolider un projet

L’action **Consolider le projet** copie le `.mbah` et tous ses médias référencés dans un dossier
cible. Elle est utile avant un transfert vers une autre machine ou pour regrouper des fichiers
éparpillés.

La consolidation ne supprime pas les originaux. Vérifie le nombre de médias copiés et les fichiers
éventuellement manquants avant d’archiver l’ancienne organisation.
