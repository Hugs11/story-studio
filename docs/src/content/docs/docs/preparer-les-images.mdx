---
title: Préparer les images
description: Choisir le bon rôle, recadrer une image en 320 × 240 et créer une image-titre réutilisable.
---

Les images servent d’abord à identifier un choix. Une couverture présente le pack dans le menu
principal ; l’image d’un Dossier ou d’une Histoire aide ensuite l’enfant à reconnaître l’option
affichée. Prépare chaque visuel pour le moment où il sera réellement vu.

![Recadrage, niveaux et filtres d’une image](/story-studio/assets/screenshots/image-editor-dark.png)

## Couverture, vignette et images de choix

| Emplacement | Rôle |
|---|---|
| **Image Lunii** du Menu racine | couverture affichée sur la boîte pour choisir le pack |
| **Vignette catalogue** | présentation dans les bibliothèques compatibles |
| image d’un **Dossier** | catégorie ou option intermédiaire |
| image d’une **Histoire** | titre choisi avant la lecture |

L’Image Lunii est adaptée en **320 × 240** à l’export. La vignette catalogue peut conserver un
autre cadrage ; active **Utiliser la même image pour la Lunii et la vignette catalogue** seulement
si le même visuel convient aux deux usages.

## Importer et recadrer

Clique sur un champ image ou fais glisser une image depuis le
[Gestionnaire de médias](/story-studio/docs/gestionnaire-de-medias/). Story Studio ouvre l’éditeur
avant d’affecter une nouvelle source :

1. **Ajuster** remplit le cadre 4:3 et peut rogner les bords ;
2. **Centrer** conserve l’image entière, quitte à laisser de l’espace autour ;
3. fais glisser l’image pour déplacer le sujet ;
4. utilise la molette pour régler le zoom ;
5. valide avec **Utiliser cette image**.

Une miniature très détaillée devient vite illisible sur la boîte. Vérifie à petite taille que le
sujet principal reste reconnaissable et qu’aucun texte important n’est coupé.

## Corriger sans perdre la source

Le bouton **Éditer** rouvre le cadrage et les réglages mémorisés. Luminosité, contraste, saturation,
niveaux et vignettage permettent une correction légère ; ils ne remplacent pas une source de bonne
qualité.

L’image produite est un dérivé géré par Story Studio. Le fichier source choisi ailleurs sur le
disque n’est pas écrasé. **Retirer** enlève l’image du champ sans effacer cette source externe.

## Générer une image-titre depuis le nom

**Générer une image-titre** crée un visuel typographique à partir du nom du Menu racine, du Dossier
ou de l’Histoire. Ce choix est pratique pour préparer rapidement un projet cohérent avant de créer
des illustrations définitives.

Avec une sélection multiple, **Générer à partir des noms** peut préparer plusieurs images-titres en
une fois. Relis ensuite les titres longs : un nom clair dans l’Arbre n’est pas toujours lisible sur
une image 320 × 240.

## Générer avec ComfyUI

Lorsque l’intégration est activée, **Générer IA** envoie une description au serveur ComfyUI local ou
privé configuré. Le résultat rejoint la File IA puis les médias du projet. Recadre-le et vérifie-le
exactement comme une image importée.

ComfyUI reste facultatif : l’import, l’image-titre et l’éditeur d’image fonctionnent sans ce
service. Consulte [Configurer ComfyUI](/story-studio/docs/comfyui/) pour ses prérequis et ses limites.

:::tip[Astuce]
Construis d’abord toute la structure avec des images-titres simples. Une fois les choix et les
retours validés dans le simulateur, remplace seulement les visuels réellement conservés.
:::
