---
title: Espace d’édition
description: Utiliser ensemble l’Arbre, les Réglages, le Diagramme et le panneau inférieur.
---

L’espace d’édition présente le même projet sous plusieurs angles. L’**Arbre** organise sa structure,
les **Réglages** modifient la sélection et le **Diagramme** montre les chemins de navigation.

## Arbre

L’Arbre affiche le Menu racine, les Dossiers, les Histoires, les ZIP et les Liens. Utilise-le pour :

- sélectionner un ou plusieurs éléments ;
- ajouter, renommer, dupliquer, déplacer ou supprimer ;
- copier, couper et coller une branche ;
- rechercher par nom ou par couleur ;
- ouvrir les actions contextuelles d’un élément.

Les guides verticaux et l’indication de niveau permettent de suivre les structures profondes. Un
déplacement refusé distingue une boucle de Dossiers d’un dépassement de la limite d’imbrication.

## Réglages

Le panneau Réglages s’adapte au type sélectionné. Il contient les images, sons, contrôles de
navigation et options propres au Menu racine, au Dossier, à l’Histoire, au ZIP ou au Lien.

Une sélection multiple affiche uniquement les actions compatibles avec l’ensemble. Les changements
structurels restent annulables avec l’historique du projet.

## Diagramme

Le Diagramme représente les niveaux, les choix, les lectures et les retours. Il aide à repérer une
destination inattendue ou une convergence difficile à voir dans l’Arbre.

Tu peux zoomer, déplacer la vue, rechercher un élément, déplier plusieurs groupes d’Histoires et
recentrer la sélection. La sélection reste synchronisée avec l’Arbre et les Réglages.

## Organiser les panneaux

Les boutons centraux de la barre d’outils affichent ou masquent chaque panneau. Fais glisser leurs
segments ou les en-têtes pour changer l’ordre. Les séparateurs permettent d’ajuster la largeur de
l’Arbre et des Réglages.

Si tous les panneaux sont masqués, l’espace propose de réactiver directement la vue souhaitée. Les
dimensions, l’ordre et la visibilité sont mémorisés.

## Panneau inférieur et simulateur

Le panneau inférieur regroupe le [Gestionnaire de médias](/story-studio/docs/gestionnaire-de-medias/),
la File de rendu et la File IA. Il peut s’ouvrir automatiquement lorsqu’une tâche démarre ou produit
un résultat.

Le simulateur flottant permet de tester le projet depuis la racine ou depuis l’élément sélectionné
sans quitter l’espace d’édition.
