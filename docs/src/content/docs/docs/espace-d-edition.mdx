---
title: Espace d’édition
description: Comprendre l’Arbre, les Réglages, le Diagramme et le panneau inférieur.
---

L’espace d’édition est la vue principale pour travailler sur un projet. Il présente les mêmes éléments sous plusieurs angles : l’**Arbre** pour la structure, les **Réglages** pour modifier la sélection et le **Diagramme** pour visualiser les parcours.

## Arbre

L’Arbre présente la structure du projet sous forme hiérarchique. Il affiche le Menu racine, les Dossiers, les Histoires, le Message de fin lorsqu’il est utilisé, ainsi que les éventuels ZIP présents dans le projet.

Tu peux notamment :

- sélectionner un ou plusieurs éléments ;
- ajouter, renommer, dupliquer, déplacer ou supprimer des éléments ;
- copier, couper et coller une branche ;
- rechercher un élément par son nom ou sa couleur ;
- accéder aux actions propres à un élément avec le menu contextuel.

Story Studio bloque les déplacements impossibles, par exemple lorsqu’un Dossier serait placé dans son propre sous-arbre ou lorsque la limite d’imbrication serait dépassée.

## Réglages

Le panneau Réglages affiche les options correspondant à l’élément sélectionné : Menu racine, Dossier, Histoire, Message de fin ou ZIP.

C’est ici que tu modifies ses médias, ses paramètres de navigation et les options qui lui sont propres. Avec une sélection multiple, le panneau passe en modification groupée et propose les actions compatibles avec les types sélectionnés.

La sélection est partagée entre l’Arbre, les Réglages et le Diagramme : l’élément choisi dans l’Arbre ou le Diagramme devient celui édité dans Réglages.

## Diagramme

Le Diagramme donne une vue visuelle de la structure et des chemins de navigation du projet. Il est particulièrement utile pour vérifier où mène une Histoire, comment s’enchaînent les Dossiers ou où revient l’enfant après une lecture.

Tu peux zoomer, déplacer la vue, rechercher un élément, afficher ou masquer les liens de retour, limiter l’affichage à une branche et déplier les groupes d’Histoires. La sélection reste synchronisée avec l’Arbre et les Réglages.

## Organiser les panneaux

Les trois boutons au centre de la barre d’outils permettent d’afficher ou masquer l’Arbre, les Réglages et le Diagramme. Leur ordre peut être modifié par glisser-déposer, comme celui des panneaux eux-mêmes.

Les séparateurs permettent d’ajuster la largeur de l’Arbre et des Réglages. Story Studio mémorise l’ordre, la visibilité et les dimensions choisies. Si les trois panneaux sont masqués, l’espace d’édition propose directement de réafficher celui dont tu as besoin.

## Panneau inférieur et simulateur

Le panneau inférieur regroupe trois onglets : **Médias**, **File de rendu** et **File IA**. Le catalogue Médias centralise les fichiers utilisés ou disponibles pour le projet ; les deux autres onglets permettent de suivre les rendus et les générations IA, en cours ou terminés. Le panneau peut être redimensionné ou réduit.

Le simulateur flottant permet de tester la navigation depuis la racine, un Dossier ou une Histoire, et de simuler un ZIP importé sans quitter l’espace d’édition.
